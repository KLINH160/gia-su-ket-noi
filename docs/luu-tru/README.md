# Tài liệu lưu trữ

Các tài liệu trong `2026-10-18` là ảnh chụp quá trình phân tích ban đầu, còn nhắc MySQL và trạng thái trước khi có đăng ký. Không chỉnh sửa để giả vờ đã có PostgreSQL từ đầu. Tài liệu đang dùng được chỉ mục ở [hướng dẫn hiện tại](../00-huong-dan.md).

Sơ đồ use case nguồn hiện nằm tại [ca-su-dung.puml](../tai-nguyen/so-do/ca-su-dung.puml). Những đường dẫn tương đối cũ trong bản lưu trữ có thể không còn là vị trí hiện hành; dùng chỉ mục mới để tìm.
